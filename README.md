# Technical Art Portfolio Website

This folder is ready to upload to a GitHub Pages repository.

## Recommended repository

Create a public GitHub repository named:

```text
Caviarami.github.io
```

The resulting URL should be:

```text
https://caviarami.github.io/
```

Using a `Caviarami.github.io` repository keeps the portfolio URL short and stable.

## Publish with GitHub Pages

1. Create the public repository `Caviarami.github.io`.
2. Upload everything inside this `portfolio-site` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Open `https://caviarami.github.io/` and test every link on desktop and mobile.

## Alternative

If the username site already exists, create a repository named `portfolio` and upload these files there. The URL will be:

```text
https://caviarami.github.io/portfolio/
```
